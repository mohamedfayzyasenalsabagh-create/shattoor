تطبيق تعليمي تفاعلي للأطفال من الصف الأول إلى الصف السادس، مبني على مواضيع المنهاج السوري.

## شو فيه
- **تحدي يومي جديد** فيه ٥ أسئلة: رياضيات، لغة عربية، علوم، إنكليزي، وسؤال على حديث اليوم. التحدي بيختلف حسب الصف.
- **حديث شريف كل يوم** مع شرح مبسّط للطفل، وهالقسم مجاني دائماً.
- **تمارين بلا حدود** لكل مادة، مع ياسمينات وسلسلة أيام.
- **حسابات للأهل برقم الموبايل**، وبكل حساب بيقدر يكون في أكتر من طفل.
- **اشتراك لكل صف**، شهري (٣٠ يوم) أو سنوي (٣٦٥ يوم).
- **طرق الدفع**: سيريتل كاش، MTN كاش، شام كاش. الأهل بيرسلوا طلب التفعيل من التطبيق.
- **لوحة الإدارة** (حساب 0986411114)، وفيها:
  - طلبات التفعيل
  - البحث برقم الأهل والتفعيل أو الإلغاء لأي طفل وأي صف
  - إعادة تعيين كلمة السر برمز من ٨ أرقام
  - الإعدادات: الأسعار، أرقام الدفع، الواتساب، وأيام التجربة

## الملفات
| المسار | المحتوى |
|---|---|
| `app/index.html` | مصدر التطبيق (الواجهة + المحتوى + الحسابات) |
| `docs/` | نسخة الموقع المنشورة على GitHub Pages، والتطبيق بيفتحها |
| `android/` | مشروع أندرويد (WebView) يبنيه GitHub Actions |
| `firebase/firestore.rules` | قواعد حماية قاعدة البيانات |

## كيف بيشتغل
- الموقع: https://mohamedfayzyasenalsabagh-create.github.io/shattoor/
- تطبيق الأندرويد بيفتح الموقع، فأي تعديل على `docs/` بيوصل لكل المستخدمين بدون تحديث التطبيق.
- عند تعديل `android/` بيبني GitHub Actions ملف APK وبينشره بـ Releases.
- أسرار التوقيع (اختيارية، متل تطبيق نبض): `ANDROID_KEYSTORE_B64` و `ANDROID_KEYSTORE_PASSWORD`. بدونها بتنبنى نسخة تجريبية.
- `FIREBASE_SERVICE_ACCOUNT` (اختياري) لنشر قواعد الحماية تلقائياً.
